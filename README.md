This is a demo IWA intended to try the Sub Apps API feature.

## Installing the demo

* You need a ChromeOS device.
* Navigate to `chrome://flags`.
* Enable the "Sub Apps for Isolated Web Apps" feature flag.
* Navigate to `chrome://web-app-internals`
* Find "Install IWA from Update Manifest"
* Paste in the the addresss `https://subapps-demo-iwa.web.app/releases/update_manifest.json`
* Click "fetch" and "install"
